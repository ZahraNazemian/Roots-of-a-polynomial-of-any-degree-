# Roots-of-a-polynomial-of-any-degree-
Dieses Programm liest die Koeffizienten eines Polynoms aus einer TXT-Datei, berechnet alle Nullstellen und speichert die Ergebnisse in einer weiteren TXT-Datei. Funktioniert für Polynome beliebigen Grades – einfach Koeffizienten angeben und die Nullstellen erhalten!
